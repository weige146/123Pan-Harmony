## 这是什么

这是一个直接连接 123 云盘官方服务的第三方客户端，不经过任何自建服务器，账号、文件与操作结果和官方服务保持同源。

- 支持浅色、深色、跟随系统三种外观。
- 使用手机号或邮箱加密码登录；不提供扫码、短信验证码登录，也不支持导入其他客户端的登录状态。
- 登录状态保存在本机，通常有效期为 30 天；失效后需要重新登录。

## 安装与登录

### 安装

- 系统要求：HarmonyOS 6，支持手机和平板。
- 安装包请到本仓库的 [Releases 页面](https://github.com/weige146/123Pan-Harmony/releases) 下载（文件名 `123.hap`）。
- 当前安装包为**未签名版本**，普通情况下系统会阻止安装。如果系统提示未签名、校验失败或无法安装，请更换已签名的正式安装包；不要通过修改系统安全设置来绕过安装限制。
- 应用仅首次打开时申请一次剪贴板读取权限，用于识别你复制的 123 分享链接与磁力链接；之后不再重复弹窗提示。你可以拒绝，拒绝后仅影响链接自动识别，不影响登录和文件管理，后续如需开启可到系统设置中修改。

### 登录

1. 打开应用，输入手机号或邮箱与密码。
2. 登录过程由 123 云盘官方登录中心完成，客户端不保存明文密码。
3. 登录成功后会记住登录状态；到期或鉴权失效时会自动回到登录页。

> 本应用没有扫码登录、短信登录、第三方登录或“已有会话复用”入口。

## 快速上手

- **找文件**：底部进入「文件」页，右上角「更多」可进入收藏、我的分享、回收站和排序；右下角圆钮打开新建面板，可新建文件夹、上传文件或添加离线下载任务。
- **批量操作**：长按文件进入多选，拖动可连续勾选；滑到列表底部会自动加载下一页。批量操作入口在底部操作栏。
- **传文件**：底部进入「传输」页，可查看上传、下载、离线下载三类任务，并可继续添加上传、新建离线任务或刷新状态；文件页右下角的「新建」面板也能直接添加离线下载。
- **转存分享**：复制完整的 123 分享链接后，应用会提示是否转存；确认后可浏览、搜索、勾选文件，再选择保存位置。
- **整理影视**：进入「我的 → 媒体整理」，先填写 TMDB Key 并选择媒体库目录，再扫描、预览并执行整理。
- **看视频 / 听音频**：直接点开视频或音频文件。视频默认进入全屏播放（原画直链）；音频在预览页试听。
- **解压压缩包**：点开压缩包进入云解压页，勾选需要的文件，选择目标目录后提交。

## 功能详解

### 文件管理

- 支持全盘搜索，以及按常用维度升序/降序排列。
- 文件页顶栏可在列表与平铺之间切换；平铺默认自动列数（手机 3 列、宽屏 4~5 列），长按平铺图标可选 1~5 列。视频为主的文件夹自动改用视频卡（16:9 缩略图 + 标题），其余为等宽方格。收藏夹、回收站、分享列表同样支持平铺，显示方式与列数在所有文件类列表间共用并记住选择。
- 长按文件进入多选；拖动可连续选择，列表会边缘自动滚动，滑到底自动加载下一页。「全选」会先加载剩余分页，再选中全部结果。
- 文件夹行会显示该文件夹的递归总大小，与网页端一致；尚未统计完成时显示「—」。
- 支持移动、复制、删除、重命名、新建文件夹。同名文件夹会被拒绝，不会自动生成「名称 (1)」。
- 删除的文件先进入回收站；回收站支持按原位置还原、还原到指定目录、彻底删除和清空。彻底删除与清空需要二次确认。
- 收藏与取消收藏在文件详情页完成；收藏夹页展示已收藏内容。
- 会话内会记住最多 12 个目录的浏览位置和滚动位置。返回目录时恢复到原位置；搜索刷新、账号切换等操作会清空这些记忆。每个文件夹的排序方式会单独记住并在重启后保留；切换排序只重新加载当前目录，其他目录的浏览位置不受影响，搜索结果沿用当前文件夹的排序。
- 图片和视频会显示缩略图；`apk`、`ipa`、`hap`、`exe`、`msi` 安装包以及 macOS `.app` 会尝试显示包内真实图标。`dmg`、`pkg`、`aab`、`xapk`、`apks` 不做真实图标解析。

### 上传、下载与离线下载

- 上传支持单个文件或整个文件夹，文件夹会保留原有层级；单次选择上限为 10000 个文件，目录深度上限为 32 层。
- 上传支持秒传和断点续传；网络中断后可在传输中心继续。
- 上传遇到同名文件时，可选择覆盖、保留两者或跳过；该选择只作用于当前批次。
- 下载支持多节点直链、分片续传和节点自动切换；单次最多选择 10000 个文件。
- 下载优先保存到系统下载目录中本应用的文件夹；如果系统无法提供该目录，会回退到应用私有目录，此时系统文件管理器可能看不到已下载文件。
- 传输中心分为上传、下载、离线三个页签，并按「进行中 / 已完成」分组展示进度和速度。任务在切换页面时不会中断，支持暂停、继续、重试和取消。
- 离线下载仅支持磁力链接与 `http(s)` 直链，**不支持 ed2k**；单批最多 100 条。任务逐条提交，关闭添加面板不会中断本地批次；停止后不再提交后续条目，已提交到云端的内容不保证被取消；失败项可单独重试。
- 复制磁力链接后回到应用，会自动打开离线下载面板并把链接逐行填入粘贴框，只填入、不自动开始；已在粘贴框里的链接不会重复追加。普通网页、验证码和 123 分享链接不会触发这个面板。

### 分享、转存与直链空间

- 分享会创建长期有效的永久分享，并随机生成 4 位提取码；同名且已包含同一文件的分享会优先复用。
- 分享列表展示免费分享；「导出全部链接」会汇总免费与付费分享，导出为 CSV 文件保存到系统下载目录，并在完成后显示两类数量。
- 复制完整 123 分享链接后，应用会在已登录且已获得剪贴板权限的前提下提示是否转存；同一个链接在整个应用生命周期内只提示一次。
- 链接识别要求域名完整匹配，不会根据相似域名猜测。提取码只从链接或分享文案中自动提取，应用不提供手动输入提取码环节；缺少提取码时以服务端提示为准。
- 转存流程为：提示卡点「转存」→ 浏览分享内容 → 搜索并勾选文件 → 选择保存目录 → 提交。
- 直链空间只提供三项能力：文件夹启用直链空间、关闭直链空间、已启用文件获取短链。不提供直链空间浏览、长链获取或批量获取，也不做安装包后缀改写提示。
- 秒传口令按文件或文件夹生成并导出；上传种子文件后会自动把种子移入回收站，种子内容仍可用于秒传。种子文件上限为 3 MiB。
- **本应用只能生成和导出口令，不能导入口令**；需要使用口令取回文件时请通过官方客户端操作。

### 媒体整理

入口在「我的 → 媒体整理」。首次使用需要填写自己的 TMDB Key 并选择媒体库根目录。未填写 Key 时仍可按文件名整理，但无法获取海报、集标题等影视资料。

- 单次扫描上限为 2000 个文件，目录深度上限为 6 层。
- 自动识别电影与剧集，匹配海报、标题、年份、季集等信息；媒体文件的技术信息探测会选取组内代表视频，并把编码、分辨率、HDR10 / HLG / 杜比视界等信息套用到整组。
- 命名支持四份模板：电影文件名、剧集文件名、媒体文件夹、季文件夹。字段可按需要启用并拖动排序。
- 识别词、固定映射、二级分类、特别篇关键词、排除词等都可在设置中查看和修改；不提供“界面上不可见的内部默认值”。
- 详情页按「海报 → 媒体信息 → 季集调整（仅剧集）→ 文件预览」单栏展示。季集调整包含目标季、起始集、季偏移、集偏移，按媒体文件夹整组生效。
- 样片文件会自动跳过；`1x01-02`、`E01E02`、`E01+E02`、`E01-E05` 等多集写法会按区间处理；`CD1`、`Disc.2`、`DVD3` 等分段会在撞名时生成区分标签。
- 支持拆分、跳序与合并等季集策略。同名目标冲突时，后来的源文件会进入回收站；非视频旁挂文件按规则处理，也可能进入回收站。这些文件可从回收站找回。
- 执行前一般会直接开始；只有本次勾选项目之间出现同名目标时，才会先提醒「后者会进回收站」。执行过程中可选择停止，已成功的项目会保留并写入还原记录。
- 整理还原是独立页面，以海报墙形式展示记录，可按文件勾选还原，也可还原全部。最多保留 50 条整理还原记录；清除记录只删除本机记录，不会改动云端文件。
- 「恢复默认规则」只重置整理配置，不会删除云端文件；TMDB Key 与媒体库目录会保留。

### 在线预览

- 图片支持同目录左右滑动浏览；大图会限宽解码，GIF 保留动画。图片预览不支持捏合缩放。
- 支持 TXT、Markdown、JSON、XML、YAML、常见源码和 NFO 等文本类文件，正文按行或按块加载。
- Markdown 使用受控写法渲染：标题、列表、引用、代码、分隔线、强调、链接和图片可用；表格与四级以上标题以原文保真展示，不提供源码模式。
- Markdown 中的远程图片仅允许安全的 `http(s)` 地址；从相册插入的图片保存在本机沙箱，不作为远程图片请求。
- JSON 支持格式化展示；结构树视图仅用于不超过 4 MiB 的文件。
- 源码只做着色，不改变原始内容；XML 不加载外部实体或 DTD。
- NFO 等影视元数据会渲染为信息卡，展示海报、简介与演员等信息。
- 文本类文件超过 20 MiB、空文件或识别为二进制时，会归为“不可预览”，不提供重试按钮。
- 安装包图标解析支持 `apk`、`ipa`、`hap`、`exe`、`msi` 与 macOS `.app`；解析失败会回退为文件类型图标。

### 视频与音频播放

- 单击画面显示或隐藏控制层；双击画面中间暂停/播放，双击左右两侧快退/快进 15 秒，连续双击可累计秒数。
- 长按画面临时 2 倍速；左右横滑定位；左侧上下滑调亮度，右侧上下滑调音量。
- 支持内嵌与外挂字幕、字号与位置调整、音轨切换、自动连播和断点续播。
- 片头片尾支持用当前进度标记、±1 秒微调、跳到标记点和清除标记，并可设置自动跳过。时长未知或已播完时不能标记。
- 锁定功能可防止误触，但返回键与解锁键始终可用。
- 点开视频直接进入横屏全屏播放，使用 302 多节点原画直链，不转码、不提供清晰度切换；返回由播放页顶部栏承担。
- 视频不在预览页中内嵌播放；点压缩包进云解压、点视频进播放页，其余文件才进入预览。
- 音频试听与视频共用播放能力，支持白名单内的 `flac`、`wav`、`ape`、`dts`、`dsf` 等格式；试听从 0 开始，不继承视频进度。

### 云解压

- 点开压缩包即可进入云解压，不需要先把整个压缩包下载到本机。
- 流程为：浏览包内目录 → 勾选条目 → 选择目标目录（可新建文件夹）→ 确认提交。勾选文件夹时整项提交，由服务端递归处理子目录。
- 加密包会由服务端提示需要密码；密码只需输入一次，后续阶段会沿用。密码不会写入日志或普通错误提示。
- 解压是否可用、格式与体积限制、会员要求由 123 服务端判定，客户端不提前猜测；服务端返回的中文错误会原样展示。
- 提交成功后会关闭页面并回到文件列表。提交过程中关闭页面会提示任务将在后台继续执行；进度需要联网查看。
- 不支持本地解压，也不提供“官方失败后改成本地解压”的备用路径。

### 备注与批量重命名

- 文件详情中有独立的备注卡，内容按文件保存在本机。空内容保存等于删除备注。
- 备注编辑器是实时 Markdown 写法：支持一至三级标题、加粗、斜体、删除线、行内代码、引用、有序/无序列表、缩进/减缩进、链接、图片、分隔线和代码块。
- 工具条常驻在编辑器上方，按钮显示图标与中文标签。应用不提供颜色、字号档位和下划线，因为 Markdown 无法稳定表达这些样式。
- 列表支持四级嵌套，层级通过工具条调整。无序列表按层级显示圆点、空心圆和方块；有序列表自动编号。
- 编辑器支持相册插图与 `http(s)` 远程图片；远程地址会被安全检查，其他协议不会作为图片加载。
- 批量重命名从文件多选进入，提供 13 类可叠加规则，逐文件展示“原名 → 新名”，可忽略单项或手动修改结果。
- 正则与序号规则在执行前会校验；常用规则链可保存为预设，预设数量上限为 50，单文件重命名历史上限为 50 条。
- 只要有成功项，批量重命名就会关闭页面并刷新文件列表；全部失败时留在页面内修改后重试。

### 外观、设备与账号

- 「我的」页头像卡展示账号、会员身份与会员有效期；长期会员显示「长期有效」。
- 「我的」页右上角可切换浅色、深色、跟随系统。
- 设备管理可查看登录设备，并按要求移除设备；根据账号安全策略，移除时可能需要短信验证。
- 点「我的」页头像资料卡进入个人信息页，昵称、手机号（脱敏）、邮箱、用户编号与实名认证都在这里查看。
- 退出登录在个人信息页底部，需要二次确认。退出只清除本机登录状态，不会自动删除备注、规则、历史记录等本机数据。

## 数据与隐私

- 文件、目录、分享、传输等操作直接连接 123 云盘服务；应用不运行自建服务器，也不会把你的文件转存到第三方服务器。
- 密码只在登录时提交给官方登录中心；客户端不保存明文密码。
- TMDB Key 由用户在应用内填写，仅用于影视资料匹配，保存在本机。
- 以下内容只保存在本机，不随账号同步：登录状态、外观设置、文件备注、重命名预设与历史、整理配置与还原记录、每个文件夹的排序方式、播放进度、图标缓存。退出登录不会清除这些本机数据；卸载应用会清除应用数据。

- 剪贴板权限只用于识别你主动复制的 123 分享链接与磁力链接；应用不会上传或保存剪贴板里的其他内容。

## 常见问题与限制

- **为什么安装不上？** Releases 中的 HAP 为未签名版本，系统会阻止安装。请获取已签名的正式安装包。
- **为什么没有扫码或短信登录？** 本应用只提供手机号/邮箱加密码一种登录方式。
- **为什么复制分享链接没有提示？** 可能因为尚未登录、未授予剪贴板权限、链接不是完整的 123 域名、链接没有可识别内容，或该链接在本应用生命周期内已经提示过。
- **为什么复制磁力链接没有自动填？** 磁力链接只在已登录且已获得剪贴板权限时生效；已在粘贴框里的链接不会重复追加，普通网页、验证码与分享链接也不会触发离线面板。
- **离线下载支持哪些链接？** 只支持磁力链接和 `http(s)` 直链，不支持 ed2k；单批最多 100 条。
- **云解压会下载压缩包吗？** 不会下载包体到本机，解压由服务端完成；提交和进度查看仍然需要联网。
- **下载的文件在哪里？** 默认在系统下载目录中本应用的文件夹；系统不提供该目录时会回退到应用私有目录，系统文件管理器可能看不到。
- **为什么有些文件不能预览？** 超过 20 MiB、空文件、二进制文件、白名单外格式或服务端不支持的文件会归为不可预览；图片预览也不支持捏合缩放。
- **播放器不支持什么？** 不支持外接键盘/遥控器、截图、媒体信息、强制画面比例、逐帧、单集循环、字幕描边与粗体、投屏、画中画、弹幕、后台播放、空间音频、进度条缩略图和杜比视界徽标。
- **为什么备注、规则和还原记录换设备后没了？** 这些数据只保存在本机，不随云端账号同步。
- **媒体整理一定要 TMDB Key 吗？** 不填也能按文件名整理，但没有海报和集标题等资料；Key 需要用户自行准备并在应用内填写。
- **分享为什么只有永久分享？** 当前只创建长期有效分享，随机生成 4 位提取码，不提供自定义提取码和到期时间。
- **秒传口令能在本应用导入吗？** 不能。本应用只负责生成和导出口令，导入需要到官方客户端完成。
